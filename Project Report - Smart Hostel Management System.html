1. Abstract

Managing university student accommodation requires reliable coordination between room allocations, bed occupancies, diverse room tiers (Standard and Deluxe AC), semester billing, and dues clearance. The Smart Hostel Management System (SHMS) is a console-based Java application developed to demonstrate core Object-Oriented Programming (OOP) principles. It implements abstraction and inheritance hierarchies, dynamic polymorphic tariff calculations, encapsulation, custom exception handling, and single-file data persistence.

2. Problem Statement & System Objectives

Manual hostel record keeping results in double bed allocations, billing inconsistencies across differing room tiers, and loss of revenue when students vacate without clearing dues. SHMS resolves these through automated capacity validation, polymorphic billing formulas, and dues clearance checks.

3. Object-Oriented Architecture

The system is organized around two primary inheritance hierarchies:

  • Room Hierarchy: Abstract class Room extended by StandardRoom and DeluxeACRoom. Each subclass overrides calculateTotalFee(months) to account for tier-specific utility and electrical tariffs.
  • Person Hierarchy: Abstract class Person extended by Student with attributes for registration number, department, room allocation, and fee balance.

4. Core OOP Principles Applied

OOP ConceptApplication in SHMS
AbstractionAbstract base classes Room and Person specify contract methods while concealing implementation details.
InheritanceStandardRoom and DeluxeACRoom inherit attributes from Room; Student inherits from Person.
PolymorphismDynamic method dispatch computes room fees based on concrete instance type (Standard vs Deluxe AC).
EncapsulationPrivate fields accessed exclusively via validated getter and setter methods.
Exception HandlingCustom exceptions (HostelException, RoomFullException, InvalidDataException) guard business operations.
